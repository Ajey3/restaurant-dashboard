# Restaurant Dashboard

A modern, responsive restaurant management dashboard built with HTML, CSS, and JavaScript.  
This project is part of my frontend development portfolio and focuses on clean UI, modular code, and real‑world functionality.

## 🚀 Features
- Live order tracking
- Menu management UI
- Responsive layout for desktop and mobile
- Dashboard metrics (orders, revenue, customers)
- Clean, modern UI with reusable components

## 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, custom spacing system)
- JavaScript (modular structure)
- Netlify (deployment)
